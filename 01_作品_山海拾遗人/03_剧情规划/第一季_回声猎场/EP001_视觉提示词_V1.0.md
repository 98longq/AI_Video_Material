# 一、全局视觉基线

## 核心风格

- 现代东方奇幻；
- 现实工业设施与山海异兽并存；
- 电影级动漫/高品质AI漫剧质感；
- 结构清晰、材质可信、光线自然；
- 有美感，但不做阴暗恐怖、血腥猎奇；
- 科技水平接近现实未来十余年的工业设备，不做霓虹赛博朋克；
- 不出现古装、仙侠门派、法阵、符箓漂浮等玄幻视觉。

## 统一负面约束

避免：
- 血腥伤口、断肢、内脏；
- 恐怖腐烂尸体；
- 重装机甲；
- 赛博朋克霓虹城市；
- 中世纪实验室；
- 魔法阵、灵气光柱、系统面板；
- 夸张发光眼睛；
- 游戏UI式满屏HUD；
- 多余尾巴、尾巴数量错误；
- 狰类狐狸化、犬化、宠物化；
- 角色脸型漂移、年龄漂移；
- 武器化过强的回收工具。

# 三、第一批3张视觉验证图

## V01｜死亡确认后尾尖异动

### 目标
一眼读懂“所有系统都说它死了，但观众看到尾巴动了”。

### 引用要求
- 场景引用A01；
- 遗骸状态引用A05；
- 不需要正面露脸，因此不必强依赖狰类头部参考。

### 正向提示词

近未来山海遗骸回收平台，巨大的山海异兽遗骸被灰白封存布覆盖在中央金属平台上，布料下清楚压出五条粗长尾巴轮廓，背景专业工作人员刚完成死亡确认正转身离开，前景最靠近镜头的一条尾尖发生极其轻微但可辨认的抬动，旁边简洁工业终端显示死亡确认通过，冷静专业的现代工业环境与微妙反常形成强烈反差，电影级动漫画面，悬念感但不恐怖，不血腥，构图清晰，观众一眼能理解信息差

### 失败判定

以下任一情况出现即重做：
- 尾巴数量不是五；
- 尾巴动作太大像已经复活；
- 工作人员正在盯着尾巴；
- 画面看不出“已确认死亡”；
- 环境像医院手术室/实验室而不是遗骸回收工业现场。

# 五、回响视觉/视频提示词规则

临终回响不是视觉法术。

### 推荐表现
- 环境背景声逐渐变闷；
- 极轻耳鸣；
- 镜头焦点短暂偏移；
- 背景景深轻微变化；
- 陆沉脚步停顿；
- 眼神寻找声源；
- 重新靠近/退后验证。

### 禁止表现
- 蓝色/金色粒子；
- 眼睛发光；
- 古文字飞出；
- 系统提示框；
- 透明山海种灵魂；
- 大段记忆闪回。

EP001的回响只有声音碎片：

**“左……”**  
**“下面……”**  
**“别让他们开——”**

# 六、H3提示词通用结构

每个镜头最终H3提示词按以下顺序写：

1. **主体身份与参考约束**；
2. **当前场景固定信息**；
3. **起始姿态**；
4. **唯一主要动作**；
5. **镜头运动**；
6. **光线/氛围**；
7. **必须保持不变的元素**；
8. **禁止动作/禁止变形**。

示例结构：

> 保持陆沉角色参考一致，位于已锁定山海遗骸回收平台，陆沉手持低活性探测器沿狰类遗骸左侧缓慢移动；当到达左腹位置时突然停步，轻微侧头寻找声音来源；镜头从侧后方稳定跟拍后轻推近；工业环境自然冷光；保持服装、脸型、探测器结构、狰类尸体姿势和五尾数量完全一致；狰类不得呼吸、睁眼或移动，不出现魔法特效。
