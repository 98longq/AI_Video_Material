# 山海种数据库

本目录只记录**已经进入当前剧情规划、并且确有制作需要**的山海种/类种设定。

它不是《山海经》百科，也不是提前把未来所有高级神兽能力写死的地方。

## 当前已建档

### 第一篇章《回声猎场》
- `狰.md`：EP001—005，狰类诈死事件
- `蛊雕.md`：EP006—010，夜间捕食区事件
- `旋龟.md`：EP011—015，生态异常/人为诱导事件

其余高级山海存在在真正进入剧情前**不提前建正式档案**。

## 命名原则

剧情前期使用“狰类个体 / 蛊雕类 / 旋龟类”等工作分类。

现代山海种与古籍名称究竟是什么关系仍属于长期谜团，因此文件名沿用古籍名称只为项目检索方便，**不代表世界观已经确认它们就是古籍中的同一物种**。

## 每份档案必须包含

1. 原典参考：只保留用于视觉和行为设计的必要依据。
2. 当前工作分类：人类现在如何称呼/理解它。
3. 视觉核心：必须稳定的轮廓与识别点。
4. 已知生态：只写剧情已经需要的规律。
5. 当前事件个体：说明本篇章个体与常态是否不同。
6. 剧情功能：它推动哪条人物、事件或谜团线。
7. 未锁定项：明确哪些内容不能被后续 AI 擅自补完。
8. 视觉/H3关键词：服务后续资产生成。

## 禁止事项

- 不擅自新增 E/D/C/B/A/S 式战斗力阶梯。
- 不把职业许可等级当作山海种战斗力等级。
- 不为了“显得强”给异兽添加与剧情无关的万能能力。
- 不提前确认《山海经》是古代真实记录、预言或其他终极答案。
- 不提前消费烛龙、应龙、鲲鹏、九尾、饕餮、相柳等高辨识度存在。
- 不因单个个体行为就给整个物种贴“善良/邪恶”标签。
