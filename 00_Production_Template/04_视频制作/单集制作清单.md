# 单集制作清单

## 编剧
- [ ] 承接上一集状态
- [ ] 开场10秒有钩子
- [ ] 本集目标明确
- [ ] 中段局势有变化
- [ ] 有实际剧情/情绪回报
- [ ] 结尾产生下一集问题
- [ ] 更新伏笔和角色状态

## 分镜
- [ ] 每镜头只有一个主要事件
- [ ] 所有镜头已编号
- [ ] 角色/场景/道具版本已标记
- [ ] 对话镜头避免长时间僵硬正反打
- [ ] 大场面前观众已经知道目标和危险

## 生成
- [ ] 标准角色参考已准备
- [ ] 标准场景参考已准备
- [ ] 关键帧通过一致性质检
- [ ] H3视频提示词按镜头写，不用剧情梗概代替
- [ ] 生成结果已按版本保存

## 后期
- [ ] 配音完整
- [ ] BGM/音效不过度抢对白
- [ ] 字幕无错字
- [ ] 镜头节奏无明显拖沓
- [ ] 前后空间、伤势、装备连续

## 归档
- [ ] 成片文件命名正确
- [ ] 使用过的关键提示词已保存
- [ ] 正式角色/场景新版本已入资产库
- [ ] 集数索引状态已更新
