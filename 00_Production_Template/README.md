# 00_Production_Template 使用说明

这是新漫剧项目的母版，不直接存放任何具体作品内容。

## 开新书
1. 复制整个母版为新的作品目录，例如 `01_作品_作品名`。
2. 在根目录 `作品目录.md` 登记。
3. 先完成 `07_IP开发`，确认作品能长期连载。
4. 再完成世界观、角色和总剧情规划。
5. 锁定角色/场景参考资产后开始EP001。

## 目录职责
- `01_世界观设定`：世界、地图、时间、势力、能力和硬规则
- `02_角色设定`：人物动机、关系、视觉版本
- `03_剧情规划`：总纲、长线集数、篇章、单集、伏笔和状态
- `04_视频制作`：分镜、镜头编号、图片与H3视频提示词
- `05_素材管理`：角色/场景/道具/风格参考和所有生成资产的管理规则
- `06_AI生成规范`：一致性、提示词、负面约束、质检
- `07_IP开发`：开书前的定位、受众、卖点和故事发动机

## 推荐单集工作顺序
`单集剧本 → 分镜 → 参考图/关键帧 → 图片生成 → 视频生成 → 配音/声音 → 剪辑 → 质检 → 成片归档`

## 重要原则
母版可以随着工作经验升级；已经创建的具体作品不要自动跟着母版变化，涉及剧情和资产的修改应单独评估。
