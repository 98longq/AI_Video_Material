# 300集路线规划模板

> “300集”是容量模板，不要求每部作品必须做到300集。先规划阶段，再根据实际数据收缩或扩展。

## 总体分段建议
| 阶段 | 参考集数 | 核心任务 |
|---|---:|---|
| 起势篇 | 001-030 | 建立主角、规则、核心钩子，第一个阶段目标完成 |
| 扩张篇 | 031-080 | 新地图、新伙伴、新势力，能力和矛盾升级 |
| 争霸篇 | 081-150 | 主角主动参与大局，旧敌升级，阶段性大胜/大败 |
| 真相篇 | 151-230 | 核心秘密逐层揭开，阵营重组，前期认知翻转 |
| 终局篇 | 231-300 | 伏笔回收、最终选择、终极冲突和结局 |

## 防注水检查
任何连续5集如果主角目标、人物关系、信息、能力或局势都没有不可逆变化，应压缩剧情。

## 扩展原则
新增篇章必须至少带来一项真正的新内容：规则、地图、人物关系、敌人机制、世界真相或主角选择，而不是换地图重复同一套路。
