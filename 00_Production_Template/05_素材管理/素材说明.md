# 素材管理规范

## 目标
保证几百集生产后仍能快速找到原始设定、参考图、提示词和生成结果，并能判断某个镜头使用了哪个角色/场景版本。

## 推荐分类
- `角色参考图/`：角色标准立绘、三视图、表情、服装、武器
- `场景参考图/`：长期复用地点的标准参考
- `道具参考图/`：武器、载具、神器、徽章等
- `风格参考/`：作品整体色彩、光影、材质和构图参考
- `生成图片/`：按集数归档
- `生成视频/`：按集数归档
- `音频/`：角色配音、BGM、音效
- `字幕/`：单集字幕与发布字幕
- `成片/`：最终导出

> Git 不保存空目录，需要目录占位时在目录中放置 `README.md` 或 `.gitkeep`。

## 强制命名规则
### 角色
`CHAR_角色名_V01_正面全身.png`

### 场景
`LOC_场景名_V01_白天.png`

### 道具
`PROP_道具名_V01.png`

### 单集镜头图片
`EP001_S001_KEY_V01.png`

### 视频
`EP001_S001_V01.mp4`

### 配音
`EP001_角色名_001.wav`

### 成片
`EP001_FINAL_V01.mp4`

## 版本规则
- V01、V02……只增不覆盖。
- 已经用于正式剧集的角色/场景版本不能直接替换。
- 角色升级换装应建立新版本并注明首次使用集数。

## 素材状态
建议在文件名旁的清单中记录：待生成 / 候选 / 已锁定 / 已使用 / 废弃。

## 禁止事项
- 不同作品素材混放。
- 用“最终版2”“新的新的”等不可追踪名称。
- 删除已经进入成片的原始参考图和提示词。
- 不记录角色换装、伤势、武器变化的起始集数。
