# 素材命名规范

## 目标
任何素材脱离文件夹后，仍能通过文件名判断它属于哪一集、哪个镜头或哪个资产版本。

## 命名示例
- `CHAR_林夜_V01_正面全身.png`
- `CHAR_林夜_V01_表情_愤怒.png`
- `LOC_旧城车站_V01_夜晚.png`
- `PROP_黑曜剑_V01.png`
- `EP012_S007_KEY_V02.png`
- `EP012_S007_V03.mp4`
- `EP012_林夜_005.wav`
- `EP012_FINAL_V01.mp4`

## 原则
1. 使用统一ID。
2. 集数与镜头补零。
3. 不覆盖正式使用过的旧版本。
4. 同一资产的中文名称保持一致。
5. 发布成片与生成中间文件明确区分。
