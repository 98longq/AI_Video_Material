> 每个正式角色锁定后，将其“不可变化关键词”和“可变化关键词”记录在这里，便于图片与视频提示词直接调用。

|---|---|---|---|---|---|
| CHAR_XXX |  |  | 表情、动作、镜头 |  | V01 |

## 固定关键词原则
优先写模型可稳定识别的客观特征：年龄感、性别、发色、发型、瞳色、脸型、体型、服装结构、饰品、武器。

## 不要混入固定描述的内容
情绪、动作、天气、镜头运动、背景地点等属于单镜头变量，不应写进角色永久描述。

## 角色版本切换
换装、成长、受伤、黑化等长期视觉变化必须建立 V02/V03，并注明首次生效集数。
