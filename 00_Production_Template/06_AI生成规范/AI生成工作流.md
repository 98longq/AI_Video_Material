# AI漫剧生成标准工作流

## A. 新角色首次进入生产
角色档案 → 视觉关键词 → 角色参考图候选 → 锁定V01 → 入角色资产库。

## B. 新场景首次进入生产
地图/剧情需求 → 场景设定 → 标准场景参考 → 锁定V01 → 入场景资产库。

## C. 单镜头
1. 从剧本确定本镜头唯一信息/动作。
2. 引用正确角色、场景、道具版本。
3. 写分镜。
4. 生成/选择首帧或关键帧。
5. 先做人脸、服装、场景一致性质检。
6. 写 MiniMax H3 镜头提示词。
7. 生成视频V01/V02……
8. 通过动作与连续性质检后锁定候选。

## D. 单集
所有镜头候选 → 粗剪 → 配音 → 根据配音微调镜头时长 → BGM/音效 → 字幕 → 连续性检查 → 最终输出。

## E. 返工优先级
剧情错误 > 角色身份错误 > 连续性错误 > 动作错误 > 构图/美观问题。

## F. 复用原则
已经稳定的角色参考、场景参考、提示词结构优先复用。不要为了每一集追求“新鲜”而重新设计整个视觉系统。
