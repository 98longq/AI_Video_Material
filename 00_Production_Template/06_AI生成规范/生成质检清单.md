# AI生成质检清单

## 单镜头通过条件
### 人物
- [ ] 脸、发型、瞳色符合当前角色版本
- [ ] 服装、武器、饰品正确
- [ ] 肢体和手部没有明显错误
- [ ] 表情符合剧情

### 场景
- [ ] 地点可辨认且符合场景版本
- [ ] 时间、天气、光线与前后镜头连续
- [ ] 关键道具位置正确

### 动作与镜头
- [ ] 核心动作完整、可读
- [ ] 没有明显瞬移/穿模/人物融合
- [ ] 运镜没有抢过剧情主体
- [ ] 镜头结束状态可以接下一镜头

### 剧情
- [ ] 画面表达与剧本一致
- [ ] 没有出现会改变剧情含义的随机内容
- [ ] 台词/旁白对应画面时机正确

### 技术
- [ ] 无乱码、水印或严重闪烁
- [ ] 分辨率/帧率满足当前制作标准
- [ ] 文件名、镜头号、版本正确

## 单集出片前
- [ ] 角色连续性检查
- [ ] 场景连续性检查
- [ ] 时间线/伤势/装备检查
- [ ] 音量和对白清晰度检查
- [ ] 字幕错字检查
- [ ] 集尾钩子是否明确
- [ ] 成片与源素材已归档

## 判定
严重角色漂移、剧情错误、连续性错误即使画面漂亮也必须返工。
